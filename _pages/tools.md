# Custom Tools

I develop practical tools with AI assistance to support experimental planning and structural data analysis. The tools listed here are available for others to use. Check the linked documentation and validate calculations against your beamline or instrument requirements before preparing samples or interpreting data.

## XAFS Sample Preparation Calculator

Plan XAFS pellets by entering the absorber, sample composition, loading, pellet diameter, and target thickness. The calculator helps compare transmission and fluorescence measurements and estimate sample and BN amounts for a chosen pellet geometry.

[Open the XAFS calculator](https://xafs-sample-lab.tianxiangchen1993.chatgpt.site/)

## PDFgetX3 GUI

An AI-assisted PyQt6 interface for PDFgetX3. It provides controls for total-scattering data processing, visualizes I(Q), S(Q), F(Q), and G(r), and exports original and Lorch-corrected results. This is an interface built around PDFgetX3 and requires a separate PDFgetX3 installation.

[View the code and installation guide](https://github.com/tianxiangchen1993/pdfgetx3gui)
